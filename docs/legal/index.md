# Legal

::: warning Draft, pending legal review
These documents are drafts and are not in effect. They will be reviewed by a lawyer before Formhaus Cloud launches.
:::

These documents cover **Formhaus Cloud**, the hosted form backend at formhaus.dev, api.formhaus.dev, app.formhaus.dev and f.formhaus.dev. Formhaus Cloud is operated by Fabrique-Futur LLC, a Wyoming limited liability company.

The open-source Formhaus project (the form definition format, `@formhaus/core`, the React and Vue renderers, the Figma plugin, the JSON Schema and `@formhaus/mcp`) is licensed under the [MIT License](https://github.com/ignsm/formhaus/blob/main/LICENSE). These documents do not apply to it. You can use the open-source project without an account and without sending any data to us.

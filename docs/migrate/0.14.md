# Migrate to 0.14

0.14 adds the built-in `time` and `hidden` field types. A definition that already used one of these names for a custom type now gets the built-in checks and, unless you pass your own component, the built-in renderer.

```bash
npm i @formhaus/core@^0.14 @formhaus/react@^0.14
npm i @formhaus/core@^0.14 @formhaus/vue@^0.14
```

## Changes

| Area | Old (0.13) | New (0.14) | Action |
|---|---|---|---|
| Definition | `time` was a custom type without checks | 24-hour `HH:mm` or `HH:mm:ss`; other values fail with "Enter a valid time" | Store 24-hour times, or rename your custom type |
| Definition | `hidden` was a custom type without checks | Checked as text; its errors are form-level errors | Store text values, or rename your custom type |

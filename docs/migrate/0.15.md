# Migrate to 0.15

0.15 reads definition format 1.2, which adds `props` on fields. Two runtime changes can change submitted values.

```bash
npm i @formhaus/core@^0.15 @formhaus/react@^0.15
npm i @formhaus/core@^0.15 @formhaus/vue@^0.15
```

## Changes

| Area | Old (0.14) | New (0.15) | Action |
|---|---|---|---|
| Values | A field that started hidden, or was hidden and shown again, came back empty, except a `hidden` field | It gets its `defaultValue` or initial value back unless the user edited it | Remove workarounds that set defaults after a field appears |
| Groups | A group shown again started with `defaultItems` new items | An unedited group gets its initial items back; an edited one starts with `defaultItems` | None |
| Values | A cleared `number` input wrote `''` | It writes `null` | Treat `null` as a cleared number on the server |
| Format | `FORMAT_VERSION` was `"1.1"` | `"1.2"` | Set `"formatVersion": "1.2"` on definitions with `props` |
